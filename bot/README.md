# Αυτόματο bot συναλλαγών (Capital.com)

Το bot τρέχει **μόνο του κάθε εργάσιμη μέρα από τις ~16:35 ώρα Ελλάδας** (9:35 Νέα Υόρκη) στους υπολογιστές του GitHub και κάνει συναλλαγές **μία φορά τη μέρα**. Επειδή το GitHub συχνά καθυστερεί, ξαναδοκιμάζει κάθε 15 λεπτά μέχρι να τρέξει κανονικά (οι επόμενες προσπάθειες δεν κάνουν τίποτα). Στις αργίες του χρηματιστηρίου της Νέας Υόρκης δεν κάνει τίποτα. Δεν χρειάζεται ανοιχτός υπολογιστής ούτε πληρωμένο TradingView.

Κάθε μέρα:
1. Υπολογίζει τα σήματα της στρατηγικής από το χθεσινό κλείσιμο, ίδια με το `tradingview/strategy.pine`.
2. Κλείνει θέσεις που έμειναν ανοιχτές 20 μέρες ή που έσπασε η μεγάλη τάση τους. Το stop-loss και ο στόχος είναι ήδη καταχωρημένα στην Capital.com και εκτελούνται εκεί αυτόματα.
3. Ανοίγει νέες θέσεις, πάντα με stop-loss και στόχο.
4. Σου στέλνει ειδοποίηση στο κινητό με ό,τι έκανε.

## Φρένα ασφαλείας

| Κανόνας | Τιμή |
|---|---|
| Ρίσκο ανά συναλλαγή | 1% του λογαριασμού |
| Μέγιστες ανοιχτές θέσεις | 5 |
| Μέγιστο συνολικό ρίσκο | 5% |
| Κεφάλαιο σε θέσεις | έως 98% του λογαριασμού· καμία θέση κάτω από 2% (όπως το backtest) |
| Ίδια μετοχή | δεν την ξαναγοράζει το ίδιο πρωί που την έκλεισε |
| Δεδομένα | αγνοεί μετοχές με παλιά ή ελλιπή δεδομένα και σου το γράφει στην ειδοποίηση (⚠️) |
| Μόχλευση | 1:1 στις μετοχές (το bot ελέγχει και σταματά αν δεν είναι) |
| Φίλτρο αγοράς | νέες αγορές μόνο όταν ο Nasdaq-100 είναι πάνω από τον μέσο 200 ημερών |
| Διακοπή | αν ο λογαριασμός πέσει 15% από το υψηλότερο σημείο του (αφότου ξεκίνησε το bot), σταματά τις νέες θέσεις |
| Προεπιλογή | **λειτουργία δοκιμής**: μόνο γράφει τι θα έκανε, χωρίς εντολές |
| Live λογαριασμός | κλειδωμένος: δουλεύει μόνο στο demo, εκτός αν το ξεκλειδώσεις ρητά |

Οι ρυθμίσεις βρίσκονται στο `bot/config.json`. Το bot παρακολουθεί 49 μεγάλες αμερικανικές μετοχές από όλους τους κλάδους (λίστα `universe`): με περισσότερες υποψήφιες διαλέγει τις δυνατότερες και μοιράζει το ρίσκο. Στο 10ετές τεστ αυτό ήταν σαφώς καλύτερο από τη μικρή λίστα των 13 (δες `reports/research.md`).

## Εγκατάσταση (μία φορά, ~10 λεπτά, από υπολογιστή)

### 1. Κλειδί API στην Capital.com
1. Συνδέσου στην Capital.com. Αν δεν έχεις ενεργοποιημένη την **επαλήθευση δύο βημάτων (2FA)**, ενεργοποίησέ την, γιατί χωρίς αυτήν δεν βγαίνει κλειδί.
2. Πήγαινε **Settings → API integrations → Generate new key**.
3. Δώσε όνομα (π.χ. `bot`) και όρισε έναν **νέο κωδικό μόνο για το κλειδί**. Δεν είναι ο κωδικός του λογαριασμού σου.
4. Αντέγραψε το κλειδί που εμφανίζεται.

> ⚠️ Το κλειδί και τους κωδικούς **δεν τα γράφεις ποτέ** στη συζήτηση με το Claude, σε email ή σε αρχείο. Μπαίνουν μόνο στα GitHub Secrets (βήμα 3).

### 1β. Μόχλευση 1:1 για μετοχές
Στην Capital.com άνοιξε τις ρυθμίσεις μόχλευσης (Settings → Leverage) και βάλε **Shares: 1:1**. Με 1:1 η Capital.com δεν χρεώνει χρέωση νύχτας στις αγορές μετοχών. Το bot δεν αλλάζει ποτέ μόνο του ρυθμίσεις: αν δει άλλη μόχλευση, δεν ανοίγει θέσεις και σε ειδοποιεί.

### 2. Ειδοποιήσεις στο κινητό
1. Κατέβασε τη δωρεάν εφαρμογή **ntfy** (Android / iPhone).
2. Πάτα **+** και γράψε ένα δύσκολο όνομα θέματος που ξέρεις μόνο εσύ, π.χ. `andreas-bot-7f3k9q`.

### 3. Μυστικά στο GitHub
Άνοιξε **github.com/andrew711994a-netizen/tesla-live → Settings → Secrets and variables → Actions**.

Στην καρτέλα **Secrets**, πάτα **New repository secret** και πρόσθεσε ένα ένα:

| Name | Τι βάζεις |
|---|---|
| `CAPITAL_API_KEY` | το κλειδί από το βήμα 1 |
| `CAPITAL_IDENTIFIER` | το email σύνδεσης στην Capital.com |
| `CAPITAL_PASSWORD` | τον κωδικό **του κλειδιού** από το βήμα 1 |
| `NTFY_TOPIC` | το όνομα θέματος από το βήμα 2 |

### 4. Πρώτη δοκιμή
1. Πήγαινε **Actions → Trade → Run workflow** και άφησε τσεκαρισμένο το «Μόνο δοκιμή».
2. Σε 1–2 λεπτά θα πάρεις ειδοποίηση. Στο GitHub, μέσα στο run, θα δεις αναλυτικά τι θα έκανε.

### 5. Ενεργοποίηση στο demo
Όταν είσαι σίγουρος ότι όλα δουλεύουν:
1. Στην καρτέλα **Variables** (δίπλα στα Secrets), πάτα **New repository variable**.
2. Βάλε Name `DRY_RUN` και Value `false`.

Από την επόμενη εργάσιμη το bot ανοίγει πραγματικές θέσεις **στο demo** σου.

## Διακοπή
- **Άμεσα:** Variables → `BOT_ENABLED` = `false`.
- **Πίσω σε λειτουργία δοκιμής:** `DRY_RUN` = `true`.
- **Κλείσιμο θέσεων:** από την εφαρμογή της Capital.com, όπως πάντα.

## Σημαντικό
- **Το repository είναι δημόσιο,** οπότε τα logs του GitHub Actions τα βλέπει όποιος ξέρει πού να κοιτάξει. Το bot δεν γράφει ποτέ υπόλοιπα, ποσά ή στοιχεία λογαριασμού, μόνο σύμβολα και τιμές.
- **Μην ανοίγεις χειροκίνητα θέσεις στο demo** στις ίδιες μετοχές με το bot, γιατί θα τις θεωρήσει δικές του.
- **Τα αποτελέσματα του backtest** είναι στο `reports/backtest.md` και ενημερώνονται αυτόματα όταν αλλάζει ο κώδικας.
- Δεν αποτελεί επενδυτική συμβουλή. Ακόμα και καλό backtest δεν εγγυάται κέρδη στο μέλλον.

## Ημερολόγιο και καθημερινός έλεγχος
Όταν το bot κάνει πραγματικές κινήσεις (demo ή live), γράφει στον φάκελο `journal/`:
- `trades.csv`: κάθε κλεισμένη συναλλαγή, με αποτέλεσμα σε % και σε R (πόσες φορές το αρχικό ρίσκο κέρδισε ή έχασε),
- `daily.csv`: μία γραμμή τη μέρα, με τις ανοιχτές θέσεις σε % και τις κινήσεις της ημέρας,
- `positions.json`: τις θέσεις που άνοιξε το bot, για να καταλαβαίνει πότε έκλεισαν από stop ή στόχο.

Το Claude διαβάζει το ημερολόγιο κάθε εργάσιμη μετά το κλείσιμο της αγοράς και γράφει αναφορά: σύγκριση με το backtest, προβλήματα, ιδέες για βελτίωση. Καμία αλλαγή στη στρατηγική δεν μπαίνει χωρίς έλεγχο στα 10 χρόνια ιστορικού και χωρίς την έγκρισή σου.
